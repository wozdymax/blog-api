# Blog API & Admin Panel

REST API и административная панель для мобильного приложения "Блог". Разработано на Laravel с использованием Filament.

## Возможности

- **Аутентификация**: Регистрация и вход через Laravel Sanctum (токены доступа).
- **Управление публикациями**: CRUD операции для постов с пагинацией, сортировкой и фильтрацией по дате.
- **Админ-панель**: Полноценный интерфейс на Filament для управления пользователями и контентом.
- **Ролевая модель**: Доступ к админке ограничен только для пользователей с ролью `admin`.

## Технологии

- PHP 8.3+ / Laravel 11.x
- MySQL 8.0+
- Laravel Sanctum (API Auth)
- Filament v3/v4 (Admin Panel)
- PHPUnit (Тестирование)
